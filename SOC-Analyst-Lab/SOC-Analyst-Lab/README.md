# SOC Analyst Lab

Hands-on blue-team lab work documented step by step: building an isolated virtual lab, generating attack traffic against a deliberately vulnerable host, and then finding that activity in the security telemetry (Suricata, Kibana, Arkime).

> All activity was performed inside an isolated VirtualBox lab against an intentionally vulnerable machine (Metasploitable 2). Nothing here targets real systems.
